# Руководства пользователя

Содержимое этого каталога выкладывается на сервер в `/var/www/guides` и
открывается по адресам `https://signal.vis.ru/guides/{superadmin,admin,contractor}`.

Это **готовые к выкладке** файлы, а не исходники сборки. Отличия от того, что
собирает `docs/guides/source/build_all.py`:

- перекрёстные ссылки между руководствами переписаны с `claude.ai/code/artifact/...`
  на внутренние `/guides/...`;
- удалено подключение Google Fonts — страницы используют системные шрифты
  из запасных стеков, внешних обращений не делают вовсе.

После пересборки исходников эти две правки нужно применить заново, иначе
страницы начнут ходить наружу и уводить читателя на claude.ai.
